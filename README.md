ProiectFinal – Testare Automată Web
Descriere
Proiect de testare automată pentru aplicații web folosind Selenium, Java și TestNG. Proiectul folosește pattern-ul Page Object Model (POM) și acoperă atât testare UI cât și testare API.
Tehnologii Utilizate

Java 25
Selenium 4.18.1
TestNG 7.10.2
Maven
Page Object Model (POM)

Aplicații Testate

UI: https://demoqa.com/
API: https://jsonplaceholder.typicode.com

Acoperire Teste

9 teste UI automatizate
3 teste API automatizate
Total: 12 teste | 12 trecute

Cum se Rulează

Clonează repository-ul
Deschide în IntelliJ IDEA
Rulează prin Maven: Lifecycle → test
Raportul HTML se generează în target/surefire-reports/

Rezultate
Toate cele 12 teste trec cu succes. Raportul de execuție este disponibil în target/surefire-reports/index.html.
